# BEOE HTML Pages

Save HTML pages from https://beoe.gov.pk/list-of-oeps?show=active here.

1. Open the URL in your browser
2. Complete the human verification if prompted
3. Save each page as "Complete Webpage" (HTML)
4. Name them page1.html, page2.html, etc.
5. Run: python Backend/parse_beoe_html.py
